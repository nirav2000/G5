# Deployment and integration verification
CI runs unit tests before attempting GitHub Pages publication. Publication requires GitHub Pages source configured to GitHub Actions in repository settings, and successful environment permissions. Check the Actions run and deployed page manually; a successful commit alone does not verify deployment.

Cloud sync remains disabled until kk-syllabus Firebase config, domain authorization, secure rules, emulator tests and account identity verification are available. Never infer permission to change rules for other applications from authorization to use the Firebase project.

Shared Auth is loaded in shadow mode and falls back to local mode. Other shared libraries remain uninstalled. The notation helper currently implements only a limited subset of Grade 5. The 75-question practice is a repeated-item approximation and must not be used to predict exam distinction.
