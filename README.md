# G5 · Music Theory Studio

An independent novice-first teaching companion for ABRSM Grade 5 Music Theory, alongside Christopher Dunn's *Take Five and Pass First Time*.

## Run
Open the [GitHub Pages site](https://nirav2000.github.io/G5/) **after its deployment has been verified**, or serve the repository using a local HTTP server (ES modules do not reliably work from file:// URLs). Run `npm test` to check teaching data, engine and notation helpers.

## Status
v0.2.1 teaching preview: ten introductory guided lessons, SVG stave, audio examples, device-local event history, review signals and an **unofficial** 75-question repeated-item practice paper. Not an exam-ready course. Cloud sync and full shared library installations are not complete.

See [BUILD_PLAN.md](BUILD_PLAN.md), [docs/integrations.md](docs/integrations.md), [docs/marking.md](docs/marking.md) and [docs/RELEASE_GATES.md](docs/RELEASE_GATES.md). ABRSM and the publisher have not endorsed this project.
