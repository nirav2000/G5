# G5 — Music Theory Studio

Independent learning companion for ABRSM Grade 5 Music Theory, to use alongside Christopher Dunn's *Take Five and Pass First Time*. Not affiliated with ABRSM or the publisher.

## Status: v0.1.0 prototype

Open `index.html` in a browser. Eight original multiple-choice questions cover introductory keys, intervals, rhythm and terms. Hints are free, explanations appear after answers, and a device-local event history powers basic progress counts. The reset button removes this device's history. No account or cloud backup is active.
